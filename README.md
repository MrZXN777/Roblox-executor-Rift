# Rift

Rift is a Windows desktop Luau workspace with an editor, local script execution, syntax checking, a script library, and tools for organizing your work.

## Features

- Write and edit Luau with syntax highlighting and completion.
- Run and check scripts locally, with output, errors, and return values.
- Save scripts, browse the built-in library, and manage workspace backups.
- Customize themes, layout, and editor settings.
- Detect running Roblox Player and Studio processes on Windows.

## Important

Rift runs Luau on your computer. It does **not** inject into Roblox or execute scripts inside live games. The local runtime does not provide Roblox objects such as `game` or `Instance`.
